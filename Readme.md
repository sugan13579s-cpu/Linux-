# Linux System Monitoring Project

## Project Description
This project monitors Linux system resources
using Bash Shell Scripting.

## Features
- Date and Time
- Hostname
- CPU Usage
- Memory Usage
- Disk Usage
- System Uptime

## Technologies Used
- Linux
- Bash Shell Scripting
- Git
- GitHub

## How to Run

chmod +x scripts/system-monitor.sh

./scripts/system-monitor.sh
